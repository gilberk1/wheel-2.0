# Wheel of Horror (V2)

A wheel of fortune built in Processing. It randomly lands on one of the characters from the Five Nights at Freddy's games, then shows the character you landed on. This version uses animated character images, and [version 1](https://github.com/gilberk1/wheel) has static ones.

## Built with

Processing
